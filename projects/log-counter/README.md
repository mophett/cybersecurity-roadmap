# Log Counter

A small Python script for analyzing log files.

## Features

* Reads a log file
* Counts `INFO` messages
* Counts `WARNING` messages
* Counts `ERROR` messages
* Handles `FileNotFoundError`

## Files

* `log_counter.py` — analyzes the log file
* `log.txt` — test log file

## Concepts

* Dictionaries
* Loops
* Conditions
* Functions
* File handling
* Exceptions
