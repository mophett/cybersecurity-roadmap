# Port List Parser

A small Python script that maps port numbers to common network services.

## Features

* Processes a list of ports
* Identifies common network services
* Returns `UNKNOWN` for unsupported ports

## Example

```text
Port: 22 Service: SSH
Port: 80 Service: HTTP
Port: 443 Service: HTTPS
Port: 8080 Service: UNKNOWN
```
